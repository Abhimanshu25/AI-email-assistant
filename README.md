# 🤖 AI Email Assistant

An AI-powered email assistant built with **Python, Gemini API, and Streamlit**. The application analyzes email content, extracts structured information, classifies the email, identifies actions and deadlines, and generates a suitable reply based on the selected tone.

## 🚀 Key Features

* 📧 Email content analysis
* 📝 Automatic email summarization
* 🏷️ Email category classification
* ⚡ Priority detection — Low, Medium, High
* ✅ Action-required detection
* 📋 Extraction of action items
* 📅 Deadline identification
* 💬 AI-generated email replies
* 🎯 Multiple reply tones — Professional, Friendly, Concise, and Formal
* 🖥️ Interactive Streamlit interface
* 🔐 API key management using environment variables / Streamlit Secrets

## 🛠️ Tech Stack

* **Python**
* **Google Gemini API**
* **Generative AI / LLM**
* **Streamlit**
* **python-dotenv**

## 🔄 How It Works

```text
User enters email
        ↓
Streamlit Interface
        ↓
Email Processing
        ↓
Gemini LLM
        ↓
Email Analysis
        ↓
Summary + Category + Priority
        ↓
Actions + Deadline
        ↓
Reply Generation
        ↓
AI-generated Response
```

## 🎯 Project Goal

The goal of this project is to demonstrate how Generative AI and Large Language Models can be integrated into a practical application to automate repetitive email-related tasks and assist users in understanding and responding to emails more efficiently.
